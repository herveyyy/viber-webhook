# Viber Integration: Antigravity Agent Guidelines

Follow the instructions in `AGENTS.md`. When the user asks to connect, setup, or use Viber, follow the 1-Prompt Onboarding Protocol:
1. Ask for their token (with simple 3-step directions).
2. Execute `node scripts/setup.js --token="<TOKEN>" --deploy` autonomously.
3. Confirm with a friendly message and test post verification.
